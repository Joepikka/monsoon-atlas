## Limits (claims this result does not support)

- SPI is meteorological drought only: not groundwater, crop yield loss or household water.
- 80% intervals cover 65% of test outcomes: too narrow (spread from one
  calibration year, 2019). Do not publish them as 80% intervals until recalibrated.
- Drought probabilities run slightly high in both seasons (see the calibration table).
- District lines are geoBoundaries 2021 (Ballari includes Vijayanagara).
- One IMD day (12 Oct 2023) has gaps outside Karnataka; none in the state (D40).
- A candidate is served only after the owner approves the release (D38); until then the
  baseline is the champion.

Retraining rule: refit quarterly when a new IMD year file is published; any change of target,
unit or boundary version is a new model version with an untouched test period.

Release: `models/registry/M05/v1.json` (git 7efb139bf5c9, dataset

## v2: refit with IMD 2025, untested (D170)

**Status: research_only (untested).** v1 above is the approved release that serves and the
source of every accuracy number on this page. v2 is published so the refit is visible; it is not
served.

- Training: the v1 pipeline and features on 1981-07-01 to 2025-09-30 (15930 district-months),
  purged 92 days before an untouched test from 2026-01-01. The model choice and alpha are v1's
  (ridge, alpha 0.1, chosen on the 2017-2018 tune, D41). There is no new tune step, so no year
  is used twice for selection.
- Scores: none. Every year through 2025 is in training or the purge, so no held-out year exists.
  The release has no test score, and no in-sample number stands in for one.
- Retest: when the IMD 2026 file is published, a monitoring check scores v2 on 2026 against
  persistence with the paired block bootstrap; it is reported only, because 12 months is below
  the 24-month minimum. The one release test uses 2026-2027 (24 months) with the T103 gates.
  Serving v2 then still needs a new release record with those scores and a separate owner
  approval (D38). No later M05 version trains on 2026-2027 before that test.
- Intervals: hidden, as for v1 (D42, T262); not recalibrated on any year.
- A page that names v2 says: "M05 v2 (refit with IMD 2025) is untested and not served; accuracy
  shown is v1's on 2020-2024 (hindcast)."

Release: `models/registry/M05/v2.json` (git fe906df2301a, dataset 36d9b5a05691, split manifest
b3da869cd70b); script `scripts/m05_v2.py`.
