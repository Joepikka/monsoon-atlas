# S05 Open-Meteo ensemble: discovery (T051)

**Outcome: available.** Hourly ensemble forecasts of rain and temperature from national weather
services, free without a key, under CC BY 4.0. Forecast only: the API keeps about 4.5 days of
past values. Checked on 9 Nov 2026 (14 evidence files, fetched 05:14 to 05:17 UTC). Structured
record: [`configs/sources/s05.yaml`](../../configs/sources/s05.yaml). Evidence manifest:
[`tests/fixtures/s05/manifest.json`](../../tests/fixtures/s05/manifest.json).

## Access, licence and limits

- `GET https://ensemble-api.open-meteo.com/v1/ensemble` needs no key, account or card;
  `models` is required.
- Same licence and limits as S01 to S04: CC BY 4.0, free API for non-commercial use, fewer than
  10,000 calls a day (e02, e03). The API host robots.txt disallows crawlers (e01); D31 applies.
- Credit Open-Meteo and the weather service of the model used (ECMWF for IFS, CC BY).

## Issue time

The response has no run time. The Model Updates script builds
`https://ensemble-api.open-meteo.com/data/<model>/static/meta.json` (e05, e06). For
`ecmwf_ifs025_ensemble` on 9 Nov 2026 (e07, e09, the same before and after the call):

| Field | Value |
|---|---|
| `last_run_initialisation_time` | 2026-11-08 18:00 UTC |
| `last_run_availability_time` | 2026-11-09 02:43:50 UTC |
| `data_end_time` | 2026-11-14 21:00 UTC |
| Time step and update interval | 3 hours (interpolated to 1 hour in the API); every 6 hours |

The response has values to 23 Nov 12:00 UTC, which is 8 Nov 12:00 plus 15 days. So the hours
from `data_end_time` on are consistent with the earlier 12:00 run, not the 18:00 run. T052 must
give the run time only to hours before `data_end_time`.

Rules for T052 and every model that uses S05:

1. Read the member count from each response; never assume one.
2. Name one model per call and read its metadata before and after; keep the run only if it
   did not change. Hours at or after `data_end_time` do not belong to that run.
3. Rain is >= 0: six IFS member values are -0.1 mm (members 16 and 37, e08) and are rejected.
4. Store every run when it is issued (D07): the API has no archive of past runs.
