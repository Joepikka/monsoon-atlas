## Access

- `robots.txt` disallows `*.osm.pbf`, `*.shp.zip`, state files and updates for every user agent
  (e01), and no Geofabrik page invites scripted downloads (e02 to e04). Decision D34 stands: the
  pipeline never downloads an extract, and `S18.fetch` raises `SourceUnavailable`.
- On 12 Nov 2026 the owner downloaded `southern-zone-261111.osm.pbf` (533.7 MB, data to
  2026-11-11T21:22:47Z) in a browser from
  https://download.geofabrik.de/asia/india/southern-zone.html into `data/raw/S18` (e05). A manual
  download is not a robot. The file is stored under its SHA256 and never committed.
- Monthly update: the owner repeats the download; the agent then re-runs the check below.

Data is ODbL 1.0 (e02, e03): credit "© OpenStreetMap contributors"; derived databases stay ODbL.
Extracts are rebuilt daily around 21:00 CET (e04).

## Adapter (T022)

`src/atlas/ingest/s18.py`: `owner_file(path, url, fetched_at)` wraps the downloaded file;
`S18(state, area_wkb).parse_batches(raw, config)` streams it with pyosmium and yields bounded
tables of facilities and road ways whose centroid lies in the state polygon. Canonical columns:
[`schemas/s18.json`](../../schemas/s18.json). Tests use a 25 KB real cut of e05
(`tests/fixtures/s18_southern_zone_bengaluru_261111.osm.pbf`).
