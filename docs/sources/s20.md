## Access, limits and licence

- History: `https://earthquake.usgs.gov/fdsnws/event/1/query?format=geojson&starttime=...`;
  without `starttime` the service searches only the last 30 days (e05, e06).
- Live: `https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/*.geojson`; the docs ask
  automated applications to use these feeds (e01).
- At most 20,000 events per query; time/area limits are not enforced yet (e01, e08).
- **Licence:** www.usgs.gov returns HTTP 202 with an empty body to scripted clients (policies,
  copyrights-and-credits and robots.txt), and the browser was unavailable. Until the USGS
  statement is recorded, treat as restricted: credit the USGS Earthquake Hazards Program, keep
  raw files local, confirm before public display (H11).

Rules for T072 and the map:

1. Key events by `id`; keep a new version only when `updated` is later.
2. `status` automatic means preliminary: label its magnitude preliminary; reviewed is final.
3. Missing magnitude stays null, never 0; depth is km, times are epoch milliseconds UTC.
4. Not an emergency service: earthquake markers never imply impact or safety.

## Adapter (T072)

`src/atlas/ingest/s20.py` fetches the past-day feed hourly, or the catalogue from an explicit
`starttime` (time-ordered, at most 1,000 events, inside the box). It writes one row per
earthquake inside the box: the envelope plus `event_id`, `origin_at`, `lat`, `lon`, `depth_km`,
`magnitude`, `mag_type`, `review_status` and `updated_at` (`schemas/s20.json`, D110). `record_id`
is the event id with its update time, so a later update is a new version and a repeat is not.
Missing magnitudes stay null (`not_reported`); other event types and deleted events are dropped;
rows are not redistributable until the USGS licence is recorded. Tests read the local raw files
and skip in CI. S20 is enabled hourly.
