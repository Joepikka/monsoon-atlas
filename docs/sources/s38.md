# S38 Delhi Open Transit Data: discovery (T148)

**Outcome: blocked (owner step H04).** otd.delhi.gov.in publishes Delhi bus and DMRC metro GTFS
and a real time VehiclePositions feed, but every file and the feed sit behind a form that asks for
a purpose, an email and acceptance of the Terms, and the real time feed also needs an approved
key. Registering and accepting terms is owner step H04, so no file, key or sample was obtained.
Checked on 10 Nov 2026 (9 evidence files; two failed fetches recorded). The site was readable
with plain HTTP, so no browser tool was needed.

Structured record: [`configs/sources/s38.yaml`](../../configs/sources/s38.yaml). Evidence
manifest: [`tests/fixtures/s38/manifest.json`](../../tests/fixtures/s38/manifest.json).

| Item | Finding | Evidence |
|---|---|---|
| Static GTFS | Bus files (stops 3,464, routes 543, stop_times 378,324, trips 16,562; updated 20 Jun 2024) and DMRC files (updated 10 Aug 2023). Download is a form POST with usage type, purpose, name, email and a Terms tick; no direct file link | e02, e03 |
| Real time | `/api/realtime/VehiclePositions.pb?key=YOUR_PRIVATE_KEY` for "authorised users"; key from a registration form. No key: HTTP 401 (API host is up). No TripUpdates path is published | e04, e05 |
| Licence | No open licence. DoT copyright; use needs stated content, intent, manner, time frame and identity and DoT may refuse (clause 6); accurate reproduction with source credit is allowed (clause 22); no tracking or profiling of individuals (clause 8). Redistribution not granted | e06, e07 |
| Quota, history | No rate limit published. No archive; announcements end April 2019 and the footer says 2017-2023, so live maintenance is unknown | e05, e08 |
| Units, timestamps | Not stated. stop_times are "a rough estimate" at constant speed | e05 |
| Card | None asked for | e02, e04 |

No upstream field is claimed: the documentation lists GTFS file names only and points to Google's
GTFS pages for the format, which is not a page the source publishes. The source check (vehicle
timestamps, map matching within 100 m, trip and calendar match) could not run, and static times
are approximate, so no scheduled-delay label or ETA claim is supported. The link to
`traffickarma.iiitd.edu.in:9010/static/agency.txt` is plain http, which the project fetcher
refuses, and it was not guessed at over https.

**Retry condition:** the owner completes H04 (real time key request and static download forms,
honest non-commercial research purpose, accept the Terms), puts the key in `.env` as
`OTD_API_KEY` and places the static ZIP in `data/raw/S38`; then T148 is re-run to record one
sample, its protobuf fields, units, timestamp meaning, trip and calendar match, quota and whether
the Terms allow this use. T149 is a disabled adapter until then; T150 to T153 and T156 stay
blocked on S38.
