# S10 adsb.lol live aircraft: discovery (T059)

**Outcome: available.** Live aircraft positions around a point from the adsb.lol community
receiver network, free without a key, under ODbL 1.0. Checked on 9 Nov 2026 (10 evidence files,
fetched 07:06 to 07:07 UTC). Structured record:
[`configs/sources/s10.yaml`](../../configs/sources/s10.yaml). Evidence manifest:
[`tests/fixtures/s10/manifest.json`](../../tests/fixtures/s10/manifest.json).

## Access, licence and limits

- `GET https://api.adsb.lol/v2/point/{lat}/{lon}/{radius}`, radius in nautical miles, at most 250
  (OpenAPI file, e08). No key, account or card; api.adsb.lol has no robots.txt.
- Licence: ODbL 1.0 for the API and all published data (e02, e05, e08). Credit adsb.lol and keep
  any derived database under ODbL. No warranty of accuracy or timeliness (e03).
- No numeric limit is published. The terms say the API is free, a key earned by feeding will be
  required "in the future", and production users should make contact first (e08). Poll at most
  once per region every 300 seconds (plan cadence). If a key becomes mandatory, S10 is blocked
  until the owner decides; the agent does not feed or sign up.

## Units and times

| Field | Meaning and unit | Evidence |
|---|---|---|
| `hex` | ICAO 24-bit address, required | e08, e09 |
| `now` | **milliseconds** since the epoch in the API (the readsb reference says seconds) | e09, e10 |
| `seen_pos` | seconds before `now` that the position was updated | e09 |
| `alt_baro` | feet, or the string `ground` | e09, e10 |
| `gs` | ground speed in knots | e09 |
| `lat`, `lon` | degrees; older than 60 s moves to `lastPosition` | e09 |

The Bengaluru sample (100 nm, e10) had 20 aircraft: 5 on the ground, 3 without ground speed,
oldest position 11.3 s.

## Source-specific check: pass

1. **Stale positions:** position time is `now - seen_pos`; T060 hides positions older than 300 s.
2. **No prediction:** only supplied positions are stored or shown; no tracks are extended.
3. **No owner enrichment:** the response has registration (`r`) and type (`t`) but no owner;
   T060 keeps the hex code only and joins no other database.
4. **Privacy:** adsb.lol is unfiltered (e06). `dbFlags` marks LADD and PIA aircraft (e09); T060
   should leave them out of public output under the project's privacy rule (none in the sample).
5. Positions are receiver reports, not an official air-traffic feed: never use them for safety.
