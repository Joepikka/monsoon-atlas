# S06 Open-Meteo climate projections: discovery (T053)

**Outcome: available.** Daily CMIP6 HighResMIP climate model output for 1950 to 2050 from seven
models, free without a key, under CC BY 4.0. Model climate, not a forecast for any day. Checked
on 9 Nov 2026 (11 evidence files, fetched 06:22 to 06:25 UTC). Structured record:
[`configs/sources/s06.yaml`](../../configs/sources/s06.yaml). Evidence manifest:
[`tests/fixtures/s06/manifest.json`](../../tests/fixtures/s06/manifest.json).

## Access, licence and limits

- `GET https://climate-api.open-meteo.com/v1/climate` needs no key, account or card;
  `start_date`, `end_date`, `models` and `daily` are required.
- CC BY 4.0 from Open-Meteo (e03) and from CMIP6: all modelling groups moved to CC BY 4.0 in
  October 2022 (e09). Credit the CMIP6 programme and Open-Meteo, and cite the models (e04, e09).
- Free API for non-commercial use, fewer than 10,000 calls a day (e02). Long ranges are
  weighted: the docs' example request counts as 1844.5 calls (e04). Split a 1950-2050 pull and
  budget it.

## Scenario and bias adjustment (source-specific check: pass)

- **Scenario:** none to choose. The docs say the high-resolution models are "as close to RCP8.5
  as possible within CMIP6" and name no SSP or experiment per model (e04, e10). T054 keeps
  `scenario` null with that reason; it never writes "SSP5-8.5" or "RCP8.5" as a fact.
- **Bias adjustment:** default output is linearly bias-corrected onto ERA5-Land (monthly
  coefficients over 50 years) and downscaled to 10 km; `disable_bias_correction=true` returns
  the raw model on its own grid (e04). In 2000 at Bengaluru, MRI_AGCM3_2_S rain is 708.4 mm
  corrected and 587.1 mm raw (e06, e07). T054 must record which one it stored.
- **Not weather:** past years "should not be mistaken for actual measurements" (e04). A daily
  value is one model's climate, never a forecast or record for that date.
