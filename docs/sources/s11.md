# S11 OpenSky flight fallback: discovery (T061)

**Outcome: blocked (owner decision on terms).** OpenSky's API is documented and free within
daily credits, but "By using the OpenSky API, you agree with our terms of use", and the terms page
returns HTTP 403 to the project's scripted client. Accepting terms is an owner step (A5), so S11
stays disabled. S11 is only the fallback for S10 (adsb.lol, enabled in T060), so live aircraft are
unaffected. Checked on 9 Nov 2026 (3 evidence files, fetched 07:23 to 07:24 UTC, plus 3 failed
fetches). Structured record: [`configs/sources/s11.yaml`](../../configs/sources/s11.yaml).
Evidence manifest: [`tests/fixtures/s11/manifest.json`](../../tests/fixtures/s11/manifest.json).

## What the published docs say

Source: OpenSky's own API repository and documentation on GitHub (e01 to e03).

- REST root `https://opensky-network.org/api`; `/states/all` takes a bounding box.
- Use is for "research and non-commerical purposes"; publications, web pages included, must cite
  the OpenSky paper (Schäfer et al., IPSN 2014); the data licence model is in the terms (e02).
- Credits per endpoint family per day: anonymous 400 (per IP), standard user 4,000, active
  feeder 8,000; a box up to 25 square degrees costs 1 credit; 429 when spent (e03).
- Anonymous users get only the latest state vectors (10-second resolution); authenticated users
  need an OpenSky account and an OAuth2 API client (e03). OpenSky may block cloud-provider IPs (e02).
- Units: positions in WGS-84 degrees, `time_position` in Unix seconds, `baro_altitude` in metres,
  `velocity` in m/s (e03).

## Why it is blocked

1. robots.txt, the home page and the terms page return 403 to the scripted client (failed
   fetches). The project does not change its user agent or use another route to get past this.
2. Using the API means agreeing to terms that could not be read. The agent does not accept terms
   for the owner.
3. During the first probe, before the terms clause was read, one anonymous request to
   `/api/states/all` for a Bengaluru box returned HTTP 200. Its body was not stored, and no further
   API calls were made.

**Retry:** the owner reads https://opensky-network.org/about/terms-of-use in a browser, decides
whether the project accepts them for a non-commercial fallback, and records the decision; then
T061 runs again. An OpenSky account and API client would be a separate owner step. T062 implements
only a disabled adapter until then.
