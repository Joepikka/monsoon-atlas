# S42 Sentinel-1 / NDVI quantitative imagery: discovery (T127)

**Outcome: blocked.** The Copernicus Data Space Ecosystem (CDSE) catalogue is public, but downloading
any pixels needs a registered account and a short-lived access token. Registering and entering a
password are owner steps, so no scene was downloaded and no quantitative value was read.
Checked on 9 Nov 2026 (14 evidence files, 3 seconds apart; fetched 15:56 to 15:57 UTC, plus one
deliberate 401). Structured record: [`configs/sources/s42.yaml`](../../configs/sources/s42.yaml).
Evidence manifest: [`tests/fixtures/s42/manifest.json`](../../tests/fixtures/s42/manifest.json).
Raw files stay in `data/raw/S42`.

## What needs no account

- OData search: `https://catalogue.dataspace.copernicus.eu/odata/v1/Products?$filter=...&$expand=Attributes`
  (e06, e12, e13). Returns name, `ContentDate`, `S3Path`, size and attributes (`productType`,
  `polarisationChannels`, `cloudCover`).
- STAC search: `https://stac.dataspace.copernicus.eu/v1/collections/sentinel-2-l2a/items` (e14). Gives
  `eo:cloud_cover`, per-band assets with `proj:code`, `nodata`, `raster:scale` and `raster:offset`.

## What needs an account

Downloads (`download.dataspace.copernicus.eu/odata/v1/Products(...)/$value`), the S3 paths and the
STAC asset links all need an access token (e06, e07, e14). The token is issued for a registered
account's username and password (e07); registration needs the terms accepted and an e-mail
verified (e08), and the terms say users need to register to access EO data (e03). A request without
a token returned HTTP 401 "Token not found" (failed fetch).

## New owner step (proposed H15)

Register a free CDSE account (no card), then add `CDSE_USERNAME` and `CDSE_PASSWORD` to the ignored
`.env`. The agent never registers, accepts terms or types the password (AGENTS.md). `docs/HANDOFF.md`
is not edited here; add H15 there when the owner agrees.

## Field map

Canonical fields (section 7): `scene_id` (Name), `acquired_at` (ContentDate/Start, UTC), `product`
(productType), `asset_uri` (S3Path or asset href), `crs` (STAC `proj:code`), `cloud_fraction`
(cloudCover divided by 100, null for SAR), `bands` (polarisationChannels or STAC bands). Sentinel-2
reflectance = DN * 0.0001 - 0.1 with nodata 0 (e14).

## Source-specific check: fail

Sentinel-1 cannot yield NDVI. NDVI uses Sentinel-2 red and NIR with a cloud mask; SAR needs terrain
correction and co-registration. These cannot be exercised without pixel access.
