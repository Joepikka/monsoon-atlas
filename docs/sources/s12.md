## Access and usage policy

- Query: `https://celestrak.org/NORAD/elements/gp.php?GROUP=<group>&FORMAT=json` (e03, e04).
- robots.txt disallows `gp*.php` for crawlers (e01), but the usage policy addresses
  machine-to-machine software directly (e05); D109 applies D31.
- Download each group and format **once per update, every 2 hours**. Stop on any non-200
  response and report it to a human; repeated errors put the IP address behind the firewall (e05).

Rules for T064 and every use of S12:

1. Use OMM JSON, not TLE; keep `tle_line1` and `tle_line2` null with the 6-digit reason.
2. Hide element sets whose epoch is more than 7 days old.
3. Positions propagated from elements are provenance `inferred`, never observations.
4. No retries: any non-200 response stops the fetch.
5. Credit CelesTrak; do not republish the element sets.

## Adapter (T064)

`src/atlas/ingest/s12.py` requests `gp.php?GROUP=<group>&FORMAT=json` (default `stations`) and
refuses to run with a Fetcher that retries: the shared Fetcher now takes `retry_delays=()` for
providers that forbid retries, so a non-200 response stops after one request (D109). It writes
one row per object: the envelope plus `norad_id`, `epoch_at`, `tle_line1`/`tle_line2` (always
null, D109), `name` and the OMM mean elements needed for propagation (`schemas/s12.json`).
Elements out of range or missing fail the response. Element sets more than 7 days older than
the fetch are flagged `stale`. Provenance is `official` (published 18 SDS elements); any position
propagated from them is a separate inferred product. `redistribution_allowed` is false. The tests read
the OMM response (e08) from the local raw store and skip in CI; it is not committed. S12 is enabled in `configs/states/ka.yaml`.
