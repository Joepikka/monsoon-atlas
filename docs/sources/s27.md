# S27 KSNDMC gauges: discovery (T077)

**Outcome: blocked.** KSNDMC's site refuses HTTPS, and over plain HTTP it serves only an
unconfigured ASP.NET template with three undocumented rain-gauge endpoints: no station list,
units, licence or terms. Checked on 9 Nov 2026 (2 evidence pages read over HTTP under D112, plus
3 failed HTTPS connections). Structured record:
[`configs/sources/s27.yaml`](../../configs/sources/s27.yaml). Evidence manifest:
[`tests/fixtures/s27/manifest.json`](../../tests/fixtures/s27/manifest.json).

## Findings

| Check | Result | Evidence |
|---|---|---|
| `https://ksndmc.org/` | connection refused on port 443 | failed fetch |
| `https://www.ksndmc.org/` | name does not resolve | failed fetch |
| `https://varunamitra.karnataka.gov.in/` | no connection | failed fetch |
| `http://ksndmc.org/` | ASP.NET template "Home Page" | e01 |
| `http://ksndmc.org/Help` | template API help: `GetTrg24HourRainfallByDate?trgId=...` and two more, "No documentation available" | e02 |

The endpoints need telemetric rain gauge IDs that no page lists; calling them with guessed IDs
would invent inputs, so no data was requested. The Fetcher and all adapters stay HTTPS-only
(D112), so even documented HTTP endpoints could not be ingested.

**Retry:** KSNDMC serves gauge data over HTTPS with a station list, units and terms, or publishes
an open dataset. Historical hobli rainfall is assessed separately as S29 (OpenCity, T079).
